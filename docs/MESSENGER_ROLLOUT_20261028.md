## Восстановление

Защищённая папка сервера: `/root/empin-messenger-20261028.9Rxm73`.

- `database-before-apply.sql` — полный снимок перед применением миграций;
- `rollback-files/`, `rollback-manifest.json`, `applied-files.json` — прежние файлы, хеши, права и журнал замены;
- `deployment-success.json` — подтверждение успешного применения;
- `web-files-before.json`, `web-status-before.json` — исходные контрольные суммы и HTTP-статусы веба;
- `test-app/`, `tests-passed.txt` — проверенная копия и результат PHPUnit.

Команда отката **кода**, только по отдельному решению:

```bash
python3 /root/empin-messenger-20261028.9Rxm73/deploy.py rollback
```

Откат проверяет хеши, чтобы не затереть более поздние изменения. Возвращает прежние существовавшие файлы, новые переносит в архив внутри папки восстановления. Дополнительные колонки сохраняются: общий rollback миграций и восстановление всего SQL-снимка автоматически не выполняются, чтобы не потерять новые пользовательские данные.

Локальный пакет и журнал: `outputs/deploy-messenger-20261028` в папке задачи, вне репозитория backend. Секреты и SQL-снимок в Git не добавляются.
