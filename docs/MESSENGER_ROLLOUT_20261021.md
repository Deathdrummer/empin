## Резервные копии и откат

Приватная папка сервера: `/root/empin-messenger-20261021.W8uPes` (доступ root).

- `database-before-apply.sql`: полный снимок базы непосредственно перед миграциями, 25 211 319 байт.
- `rollback-files/`: прежние версии заменённых файлов.
- `rollback-manifest.json`, `applied-files.json`: SHA-256, владельцы и права.
- `deployment-success.json`: результат выкладки.
- `deploy.py`: проверка и возврат файлов.

Команда возврата прежнего кода (выполнять только при отдельном решении об откате):

```bash
python3 /root/empin-messenger-20261021.W8uPes/deploy.py rollback
```

Откат проверяет контрольные суммы, чтобы не затереть более поздние изменения. Новые файлы перемещаются в `rolled-back-new/`, существовавшие восстанавливаются из копий с исходными правами. Добавленные таблицы и поля сохраняются: автоматический `migrate:rollback` не выполняется, чтобы не удалить новую переписку. Восстановление всего SQL-снимка также не выполняется автоматически, поскольку оно потеряло бы данные, появившиеся после снимка.

Локальный пакет и лог: `outputs/deploy-messenger-20261021` в корневой папке задачи. Он не содержит приватных ключей и паролей; SQL-снимки остаются только на сервере.
