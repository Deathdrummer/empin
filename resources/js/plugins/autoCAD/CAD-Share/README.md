# 🚀 CAD-Share v1.0

**Монолитное решение для расшаривания CAD файлов**

## 📦 Что в комплекте

- `CAD-Share.bat` - Запускаемый файл для Windows
- `CAD-Share.exe.js` - Основной код приложения
- `README.md` - Эта инструкция

## 🎯 Для проектировщиков

### Быстрый старт (2 минуты):

1. **Скачать папку CAD-Share** в папку с вашими .dwg/.dxf файлами
2. **Двойной клик** по файлу `CAD-Share.bat`
3. **Скопировать ссылку** из окна в настройки сайта

### Что происходит:
- Запускается веб-сервер на вашем компьютере
- Ваши CAD файлы становятся доступны по ссылке
- Сайт может их конвертировать в JSON

### Требования:
- ✅ Windows 7/10/11
- ✅ Node.js (скачается автоматически если нужно)
- ✅ CAD файлы в папке (.dwg, .dxf)

## 🌐 Доступ из интернета

### Вариант 1: Локальная сеть
Используйте `http://localhost:8000` - работает если сайт на том же компьютере

### Вариант 2: localhost.run (автоматически)
Если есть SSH, создается публичная ссылка типа:
`https://abc123.localhost.run`

### Вариант 3: Tailscale (рекомендуется)
1. Установить Tailscale: https://tailscale.com/download
2. Получить IP адрес (100.x.x.x)
3. Использовать `http://100.x.x.x:8000`

## ⚠️ Важно

- **НЕ ЗАКРЫВАЙТЕ** окно CAD-Share во время работы
- **ПЕРЕЗАПУСТИТЕ** если поменяли файлы в папке
- **СКОПИРУЙТЕ** новую ссылку после каждого запуска (для localhost.run)

## 🛠️ Техническая поддержка

**Если не запускается:**
1. Установите Node.js: https://nodejs.org/ru/download/
2. Проверьте антивирус (может блокировать)
3. Запустите как администратор

**Если файлы не видны:**
1. Проверьте что .dwg/.dxf файлы в той же папке
2. Перезапустите CAD-Share.bat
3. Обновите браузер
