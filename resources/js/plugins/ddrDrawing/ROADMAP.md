# ddrDrawing Plugin - Roadmap

## Текущий статус
- ✅ Модульная архитектура реализована
- ✅ Базовые инструменты (Select, Rectangle)
- ✅ Контекстное меню с портами
- ✅ Масштабирование и навигация

## Планируемые функции

### 1. Выноски для фигур и линий
- **Цель**: Добавление текстовых подписей к элементам
- **Компоненты**: 
  - `AnnotationTool.js` - инструмент создания выносок
  - `Annotation.js` - класс выноски
  - Контекстное меню: "Добавить выноску"
- **Особенности**: 
  - Линия-выноска с текстом
  - Автоматическое позиционирование
  - Редактирование текста на месте

### 2. Соединительные линии
- **Цель**: Связывание фигур стрелками/линиями  
- **Компоненты**:
  - `LineTool.js` - инструмент рисования линий
  - `ConnectionManager.js` - управление связями
  - Логика привязки к портам
- **Особенности**:
  - Привязка к портам фигур
  - Различные типы стрелок
  - Автоматическая маршрутизация

### 3. Опорные точки соединительных линий
- **Цель**: Редактирование формы линий через контрольные точки
- **Компоненты**:
  - `ControlPoint.js` - класс опорной точки  
  - `LineEditor.js` - редактор линий
  - События drag&drop для точек
- **Особенности**:
  - Визуальные маркеры точек
  - Добавление/удаление точек
  - Плавные кривые Безье

### 4. Направляющие линии для выравнивания  
- **Цель**: Помощь в точном позиционировании
- **Компоненты**:
  - `SnapGuides.js` - система направляющих
  - `AlignmentTool.js` - инструмент выравнивания
  - Визуальные подсказки
- **Особенности**:
  - Магнитное выравнивание
  - Временные направляющие
  - Выравнивание по центру/краям

### 5. Дополнительные фигуры
- **Цель**: Расширение набора примитивов
- **Компоненты**:
  - `CircleTool.js` - окружности  
  - `TextTool.js` - текстовые блоки
  - `ArrowTool.js` - стрелки
  - `PolygonTool.js` - многоугольники
- **Особенности**:
  - Единый интерфейс создания
  - Настраиваемые свойства
  - Стили и цвета

### 6. Группировка и слои
- **Цель**: Организация сложных схем
- **Компоненты**:
  - `GroupTool.js` - группировка элементов
  - `LayerManager.js` - управление слоями
  - UI панель слоев
- **Особенности**:
  - Вложенная группировка  
  - Видимость слоев
  - Блокировка редактирования

### 7. Экспорт и сохранение
- **Цель**: Сохранение работы пользователя
- **Компоненты**:
  - `ExportManager.js` - экспорт в форматы
  - `StorageManager.js` - сохранение/загрузка
  - Форматы: PNG, SVG, PDF, JSON
- **Особенности**:
  - Высокое качество экспорта
  - Сохранение в localStorage
  - Восстановление после перезагрузки

## Порядок реализации

### Фаза 1 (приоритет высокий)
1. Соединительные линии
2. Выноски для фигур  
3. Дополнительные фигуры (круг, текст)

### Фаза 2 (приоритет средний)  
4. Опорные точки линий
5. Направляющие для выравнивания
6. Группировка элементов

### Фаза 3 (приоритет низкий)
7. Слои
8. Расширенный экспорт
9. Автосохранение

## Архитектурные принципы

- **Модульность**: каждая функция = отдельный модуль
- **Расширяемость**: новые инструменты через наследование BaseTool
- **Совместимость**: сохранение существующего API  
- **Производительность**: оптимизация для больших схем
- **Пользовательский опыт**: интуитивный интерфейс

## Технические требования

- ES modules (import/export)
- Совместимость с JointJS 4.x  
- Поддержка сенсорных устройств
- Отмена/повтор действий (Command pattern)
- Горячие клавиши
- Контекстно-зависимые меню
